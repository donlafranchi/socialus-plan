# Keeping the lights on: run cost and contributor target

List prices checked 2026-10-07 on vendor pages unless marked unverified.

## Income pathway

1. Lights on: the true monthly cost, funded by member contributions (this file).
2. Contributions: how members contribute, and a public cost-vs-raised view per metro.
3. Transaction income: a fee on member commerce, set using comparable apps' models.
4. How we're different: no VC or PE; members are the investors and the only people paid out; surplus to the platform first, then members; never extractive.

Sequencing: beta gathers feedback; this runs alongside post-beta fixes; contributions go live before production (Apr–May 2027).
