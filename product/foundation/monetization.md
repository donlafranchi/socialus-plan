# Monetization

**The rule, and the only rule:** does this benefit the many instead of enriching the few? Pass that test and the mechanism is open — fees, dues, a producer-sales cut, advertising, sponsorship, anything. No option is refused by category. The platform takes only what it needs to run and gives back as much as it can to the communities that generated it.

This page says what's current; git log is the history.

## Priorities — work down this list until profitable

Try these in order; move to the next only once the one above it isn't enough on its own. Draft order, the PM's to reorder:

1. **Member contributions / dues** — fastest to stand up, keeps the lights on now.
2. **Producer sales cut** — the preferred long-term model; move here as soon as it can carry real volume.
3. **Advertising** — allowed, not preferred; use if 1–2 aren't covering costs.
4. **Anything else that passes the one rule** — sponsorship, services, bundling — nothing is off-limits by category.

## Still open

Who (if anyone) is paid out, any ownership/investor structure, incorporation, and the exact rate or amount for anything on the priorities list above. None of it is settled beyond the one rule and the priority order.
